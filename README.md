# NEXUS AI Automation

Premium one-page agency website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Project media

Place the supplied project demos at:

- `public/videos/demo1.mp4`
- `public/videos/demo2.mp4`
- `public/videos/demo3.mp4`
- `public/videos/demo4.mp4`

They autoplay only when their cards are visible and pause outside the viewport. If a video is absent, the polished fallback panel remains visible.
